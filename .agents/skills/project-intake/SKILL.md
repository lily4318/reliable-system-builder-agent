# project-intake｜工作技能

## 開工
讀根 AGENTS.md、適用角色指令與正式專案來源。使用私人工作區的 `context` 取得既有產物及有效經驗，不把工作區當成正式來源或額外授權。前置產物：依任務所需。缺件時先完成必要前置或說明阻塞；不假造產物。

## 執行
先辨識新建、維護或改善 Agent；讀既有規格、私人偏好及先前回答。新建網站使用 src.website_discovery 的 13 題，已答預填，不重複追問。可啟動本機訪談 UI。明示需求、推導、未知分開，逐項可編輯；輸出需求紀錄，等待使用者確認，不能提前授權施工。

## 交付與接續
保存實際工作成果到已授權私人工作區並以 `handoff` 登錄 requirements；產物應包含需求來源、實際完成、驗證結果、未決與下一步。透過 `context` 回讀產物，下一技能讀內容而非只讀完成旗標。只有真實驗證才可稱完成；角色未被實際啟動時標記單 Agent 協作。外部寫入、正式部署與發布另需授權。
