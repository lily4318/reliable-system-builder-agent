# 通用產物範本（複製到授權私有工作區使用）

需求／規格：ID、原始明示需求、推導、使用者有效決策、未決、頁面／流程、資料、權限、非功能、驗收、MVP。
架構：需求 ID、替代方案、理由、元件、資料模型、狀態機、介面、例外及回退。
任務計畫：任務 ID、依賴、角色、實際文件／程式、驗收、狀態。
實作／QA：變更檔案、版本、執行命令、觀察結果、失敗、修復、仍待核事項。
案例卡：情境、可重現錯誤、根因與假設區分、修復、前後測試、證據來源及適用限制。
經驗卡：類別、topic、實際學到的原理、證據、basis、適用場合、反例；私人記憶不得公開。

## 訓練任務書

每項實際訓練用一份任務書，從[訓練主檔的目前工作](../docs/AGENT_CAPABILITY_TRAINING.md#目前工作)開啟。新一輪只填與該任務有關的欄位。

| 要回答的問題 | 填寫內容 |
| --- | --- |
| 本次要驗什麼 | 能力、來源或教材單元、交付給誰，做到哪裡算完成。 |
| 可行範圍是什麼 | 已確認需要、期限、人力／可投入時間、已有作品或測試、待驗能力與延後事項。 |
| 如何接手 | 當前版本、主責與接手角色、所需原件、階段產物及存放位置。 |
| 怎麼知道做到了 | 具體驗收、正反情境、實際結果與限制。需求變更時替換有效條件並標出要重驗的部分。 |
| 下一步怎麼走 | 成品、剩餘未決及下一可驗工作寫回主檔。歷史證據指向原版本。 |
