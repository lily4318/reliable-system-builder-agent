# 研究方法互動教學 APP（TD-005 M2-1）
本案例僅限公開合成教學示範，非正式研究或真受試者分派。使用者確認的第一版範圍：單頁、兩組等額隨機分派、可重現 seed、合成分數呈現及 UTF-8 CSV、桌面/手機、無登入/資料庫/追蹤/額外成本。M2-1 已明示施工，M2-2、C3/M4 另授權。

## 一頁交付約定與架構
目標：教授可用同參數重現合成資料，學生比較種子、組別與描述性平均。採三份純靜態檔（index.html、style.css、app.js）及瀏覽器內運算；無套件、API、後端、個人資料或外部資源。本輪不部署。既有 QA 的 Chromium CDP 重用，不新增框架。技術細節在既定範圍內選擇：20–100 偶數、種子 0–4294967295，32-bit Mulberry-style PRNG + Fisher–Yates 等額洗牌及整數拒絕抽取，A/B 基準 50/58，三個 0–10 亂數之和減15。合成規則版本 sim-v1（非 Agent release），確定性示範不代表科學效度、均勻性保證或正式分派工具。教授仍決定實際研究方法與驗收。
- R1 兩組各 n/2、ID 唯一連續、同參數 seed 重現、修改 seed 可改變結果。
- R2 合法上下界、奇數/空值/越界/非整數拒絕，修改參數即清空舊結果/停用下載，錯誤回饋及修正可再產生。
- R3 畫面全列、兩組平均依實際資料計算；CSV 實際下載全部列及參數、版本，與畫面一致。
- R4 375/1280 實體 CSS viewport、無橫向頁面溢位、可用鍵盤/標籤、CSP、純文字 DOM、固定欄位無任意字串、零儲存/外連。僅基本可及性，非完整 WCAG 驗收。
- R5 明示合成、無真人資料及推論/測量精度宣稱；完全無雲服務、正式部署。
## 操作
下載三檔至同一資料夾，先嘗試在允許本機檔的瀏覽器開啟 index.html；若瀏覽器政策阻擋，使用既有本機靜態預覽（不公開、無新增服務）。輸入樣本數及種子，按產生；比較兩組平均，捲動完整表；CSV 可供 Excel/R/SPSS 匯入。CSV 六欄見頁面，ASCII 數字/固定枚舉、UTF-8。相同 n/seed/sim-v1 可重現。無真實資料上傳。
## 驗收
在候選 checkout 執行 python -m unittest discover -s tests -p test_research_methods_app.py -v，既有 CI discover 同時執行其他回歸。測試 server 僅 loopback 三檔、真 Chromium DOM/Tab/下載檔案 byte 讀回。實際 log 及 commit 見原 TD-005 決策與主檔；不將 CI 當真人 UAT 或外部網址驗收。M2-2 真新對話接續/適用新手引導另作；C0–C6 另行管理，不能以此候選當線上部署物已上線。
