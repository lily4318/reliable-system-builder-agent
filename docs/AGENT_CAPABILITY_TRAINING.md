## 整套團隊如何工作

1. 接案先用全圖找既有能力與缺口。系統負責人讀當前任務，PM 確認交付目的、期限、可投入工時和團隊已驗能力。
2. 每輪寫一份任務書，列出來源、主責、預期成品、交接與停點。架構師定責任邊界，開發者交可驗的成果，安全及維運依題目參與。
3. 主責完整讀來源，解釋原理、條件與反例，整合到既有技能，再實作、正反測和修復。QA 按同版需求獨立驗收，學習評估者追蹤換題後的應用。[穩定訓練準則](training/CORE_TRAINING_PRINCIPLES.md)、[技能目錄](../config/skill-catalog.json)、[任務書格式](../templates/WORK_ARTIFACTS.md#訓練任務書)
4. 新需求經確認即替換主檔與受影響的任務、驗收及下一步。舊條件從現行入口移除，變更理由留在版本紀錄。收工寫回實際成果、未驗事項與下一位接手者。用沒有前文的工作階段從同一入口重讀，驗證選到的是否為新版。
