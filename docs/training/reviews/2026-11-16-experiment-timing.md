## 實際閱讀及批判性蒸餾
- W3C High Resolution Time Level 3（2026-09-01 WD）：https://www.w3.org/TR/2026/WD-hr-time-3-20260901/ 。區分 wall clock 與單調計時，performance.now() 用同一 context 的 time origin；系統時鐘調整與時間精度保護不能忽略，跨 reload 不直接相減。
- MDN requestAnimationFrame：https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame 。callback 在 repaint 前，timestamp 為前一 frame 時間資訊，不代表光子出現時間。rAF 在背景可能暫停。用 DOM 寫入及下一 rAF 代理時間，分開 requested_at、dom_write_at、frame_ready_at、response_at、handler_at、finished_at；RT 為同一頁 response timestamp - DOM write proxy。
- MDN Event.timeStamp：https://developer.mozilla.org/en-US/docs/Web/API/Event/timeStamp ；KeyboardEvent：https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent 。事件建立時間與 handler 實際處理時間需分開，瀏覽器會降低精度；防 repeat/held key、避免跨 time origin。
- MDN visibilitychange：https://developer.mozilla.org/en-US/docs/Web/API/Document/visibilitychange_event ；jsPsych 8 interaction data：https://www.jspsych.org/v8/reference/jspsych-data/ 。保留 focus/blur/hidden/pagehide 等資料品質事件，不將失焦、逾時與正常反應混為一談；生命週期事件並非可靠持久化保證。排除或重試政策由研究者核准。
- jsPsych timing accuracy：https://www.jspsych.org/latest/overview/timing-accuracy/ ；Anwyl-Irvine et al., Realistic precision and accuracy of online experiment platforms, web browsers, and devices, DOI 10.3758/s13428-020-01501-5：https://pmc.ncbi.nlm.nih.gov/articles/PMC8367876/ 。線上平台、OS、螢幕及輸入裝置均可能影響時序；舊實測不代表當前任意設備。比較自寫最小 DOM PoC（訓練原理與受控錯誤）及成熟 jsPsych/PsychoJS（具現成試驗功能、仍需按研究需求驗證及固定版本）；精確到 frame 或物理反應的研究需按設計使用專業硬體量測，例如光電感測或外部 response 裝置。不得從高解析 API 推論毫秒物理準確度。本次未引入新套件到產品或選定所有真研究的平台，既有本機 Playwright 僅用於測試。這是獨立專業來源學習，非指定教材單元已讀或完整七階段完成。
