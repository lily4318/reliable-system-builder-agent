# 教材進度摘要

## 當前需求

第一版，公開合成練習。教學助理的一句需求是「我想看工程教材學得怎樣，能幫我做一個進度總覽嗎？」題目使用既有公開教材表。演練需求方的期限、可用人力、要拿去做哪個決定與可接受的交付形式都還未知。

## 角色與交接

本題練習「資料不足時做可行性訪談，再把已確認範圍交給下一角色」。系統負責人讀[訓練主檔](../../AGENT_CAPABILITY_TRAINING.md)，PM 重用已知資料並提出最少必要的問題。開發者可讀[教材矩陣](../curriculum-coverage.json)與[既有能力差距核對](../reviews/2026-11-23-csharp-mvc-sql-capability-gap.md)，指出已有哪一類可查驗的資料。架構師接到確認後的範圍才選擇交付形式，QA 用同版任務書驗收。

第一版交付物是一份短的範圍交接。驗收看接手者是否指出期限與人力、使用目的及能力證據，能否區分可行工作與仍待確認的交付承諾。停在可交給演練需求方回答的地方。題目中的日期、資源和角色都屬合成情境。
